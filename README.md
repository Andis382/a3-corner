# A3 Corner menu

One-page digital menu for A3 Corner Coffee Shop. It is plain HTML, CSS and JavaScript:
open `index.html`, or put the whole folder on any static host (for example GitHub Pages).

## Changing things

- **Prices and items:** edit the `MENU` list in the `<script>` at the bottom of `index.html`.
- **Photos:** `images/<section-id>.jpg` is the banner (about 900px wide) and
  `images/<section-id>-sm.jpg` is the tile (about 480px wide). Replace a file and keep its name.
- **Social links:** `SOCIAL` at the top of the same script (the Facebook button stays hidden until a link is set).

## Publishing on GitHub Pages

Repository settings, Pages, "Deploy from a branch", branch `main`, folder `/ (root)`.
The address will be `https://<account>.github.io/<repository>/`.

Photos are from Unsplash, credits in `images/CREDITS.txt`.
